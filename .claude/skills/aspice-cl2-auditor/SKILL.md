# A-SPICE 4.1 CL2 작업산출물 감사

이 스킬은 A-SPICE 4.1의 Capability Level 2(CL2)를 구성하는 두 개의 공통 프로세스 속성(Process Attribute)인 **PA2.1 (Performance Management)**과 **PA2.2 (Work Product Management)**의 일반관행(Generic Practice, GP)을 기준으로, 특정 프로세스(예: SWE.1, SUP.8 등)에 국한되지 않고 산출물(work product) 자체가 CL2 수준으로 관리되고 있는지 점검한다.

이 문서에 실린 GP 목록은 A-SPICE PAM(Process Assessment Model)의 일반적인 구조를 바탕으로 한 것이며, 정확한 문구·평가 지표는 조직이 보유한 공식 A-SPICE 4.1 PAM 문서와 대조해 확인해야 한다.

## 점검 절차

1. **대상 산출물 식별**: 사용자가 지정한 작업산출물(work product) 목록을 확인한다. 지정이 없으면 저장소에서 발견되는 산출물 후보(요구사항 명세, 설계 문서, 테스트 케이스/결과, 검토 기록, 형상관리 이력, 변경이력 등)를 나열하고 사용자에게 범위를 확인한다.
2. **증거 수집**: 각 산출물에 대해 아래 PA2.1/PA2.2 체크리스트의 증거 항목을 파일 내용, 커밋/이슈 이력, 리뷰 기록 등에서 찾는다. 추측하지 말고 실제로 확인된 것만 "충족"으로 표시한다.
3. **평가**: 각 GP에 대해 NPLF 척도로 판정한다.
   - N (미충족, 0–15%): 증거 없음
   - P (부분충족, >15–50%): 일부 증거만 존재
   - L (대부분충족, >50–85%): 대부분 충족, 일부 미흡
   - F (완전충족, >85–100%): 충분한 증거로 완전 충족
4. **보고**: 산출물별로 표 형태 보고서를 작성하고, 미흡 항목에 대해 구체적 조치(action)를 제안한다. CL2 판정을 받으려면 PA2.1, PA2.2 모두 "대부분충족(L)" 이상이어야 함을 명시한다.

## PA2.1 성과관리(Performance Management) — 체크리스트

| GP | 항목 | 확인할 증거 |
|---|---|---|
| GP 2.1.1 | 프로세스 수행 목표 정의 | 해당 산출물 관련 목표/기준(일정, 품질 기준, 완료 정의)이 문서화되어 있는가 |
| GP 2.1.2 | 수행 계획 및 모니터링 | 산출물 작성/개정 계획이 있고, 진행 상황이 추적되는가(계획 대비 실적) |
| GP 2.1.3 | 수행 조정 | 계획 이탈 시 조정한 기록(이슈/변경 요청 등)이 있는가 |
| GP 2.1.4 | 책임과 권한 정의 | 산출물 작성자/검토자/승인자의 역할이 명시되어 있는가 |
| GP 2.1.5 | 자원 식별 및 제공 | 산출물 작성에 필요한 도구/템플릿/인력이 확보되어 있는가 |
| GP 2.1.6 | 이해관계자 인터페이스 관리 | 관련 팀/역할 간 커뮤니케이션·리뷰 참여 기록이 있는가 |

## PA2.2 산출물관리(Work Product Management) — 체크리스트

| GP | 항목 | 확인할 증거 |
|---|---|---|
| GP 2.2.1 | 산출물 요구사항 정의 | 산출물이 따라야 할 템플릿/구조/내용 요구사항이 정의되어 있는가 |
| GP 2.2.2 | 문서화·통제 요구사항 정의 | 명명규칙, 저장위치, 접근권한, 보존기간 등 통제 규칙이 정의되어 있는가 |
| GP 2.2.3 | 산출물 식별·문서화·통제 | 산출물에 고유 식별자, 버전, 상태(초안/검토중/승인)가 명시되어 있는가 |
| GP 2.2.4 | 검토 및 조정 | 정의된 요구사항에 따른 검토(리뷰) 기록과 그에 따른 수정 이력이 있는가 |
| GP 2.2.5 | 변경 및 버전관리 | 형상관리 도구(Git 등)로 변경이력·베이스라인이 추적되는가 |

## 출력 형식

산출물별로 다음 표를 작성한다:

```
### <산출물명>

| GP | 평가 | 근거 | 미흡 시 조치 |
|---|---|---|---|
| GP 2.1.1 | F/L/P/N | ... | ... |
| ... | | | |

종합 판정: PA2.1 = <F/L/P/N 중 가장 낮은 값>, PA2.2 = <동일>
CL2 달성 여부: <달성/미달성/조건부> — 근거: ...
```

마지막에 전체 산출물에 대한 요약표와, CL2 달성을 위해 우선순위가 높은 개선 항목(top findings)을 제시한다.
